Features

📐 Entropy Scoring

Information-theoretic strength based on accurate charset sizing (lowercase 26, uppercase 26, digits 10, symbols 32) × password length.

🔍 Breach Detection

HaveIBeenPwned k-anonymity — only the first 5 SHA-1 characters are sent. Your actual password never leaves your machine.

⌨️ Pattern Detection

Keyboard walks (qwerty, 1234), repeated characters, and leet-speak substitutions (p@55w0rd) are all detected and penalised.

🔑 Password Generator

Memorable passphrase, high-entropy random (20 chars), and alphanumeric-only (22 chars) alternatives generated locally.
